# Siva Balaji — Video Portfolio Website

A modern, high-performance personal developer portfolio featuring interactive project showcases, full-stack application demonstrations, verified certification galleries, lanyard ID badge, and a video hero experience.

## 🚀 Live Demos
- **Firebase Hosting**: [https://portfolio-d7827.web.app](https://portfolio-d7827.web.app)
- **Netlify**: Continuous deployment via GitHub

## 🛠 Tech Stack
- **Frontend**: React 18, HTML5, Vanilla CSS & Tailwind CSS, Babel Standalone
- **Database & Cloud**: Google Firebase Firestore (`portfolio-d7827`)
- **Typography**: Syne & Inter Google Fonts
- **Aesthetics**: Glassmorphism, dark luxury theme, subtle micro-animations

## 📂 Project Structure
- `index.html` - Semantic HTML5 entry point
- `app.js` - React 18 application logic, state, and Firestore real-time listeners
- `style.css` - Custom styling, glassmorphism, animations, and responsive utilities
- `assets/` - SVG project architectures, certificates, and media
- `hero-video.mp4` - Background reel video
- `profile.jpg` - ID card photo
- `netlify.toml` - Netlify SPA redirects and asset caching rules
